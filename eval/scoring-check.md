# Scoring Check

## Objective

Evaluate whether the fit score and recommendations generated by the Application Advisor are reasonable and consistent with the selected job posting.

---

## Test Case

**Job Type**

Software Developer Co-op / Internship

**Resume**

Current resume used throughout the project.

---

## Generated Result

- Fit Score: **65 / 100**

### Observed Strengths

The advisor correctly identified strengths including:

- Python
- JavaScript / TypeScript
- Linux
- REST APIs
- Agile development
- Problem solving
- Software development experience

### Observed Weaknesses

The advisor identified several missing technologies requested by the job posting, including:

- .NET
- Angular
- Playwright
- COSMOS DB
- Visual Studio ecosystem
- Documentation experience

---

## Evaluation

The generated score is reasonable because the resume demonstrates strong software engineering fundamentals while lacking several technologies explicitly listed in the job description.

The resume is competitive for an internship or co-op position but would require learning some organization-specific technologies.

The recommendations were practical and aligned with the missing skills identified in the job posting.

---

## Observations

The scoring is generated by an LLM and should be treated as guidance rather than an exact measurement.

Different models or prompts may produce slightly different scores while still providing similar overall recommendations.

---

## Conclusion

The fit score, strengths, weaknesses, and recommendations were consistent with the selected job posting and provided useful guidance for improving the resume before applying.
