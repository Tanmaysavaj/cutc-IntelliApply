# Job Market Analysis

## Required Skills

*   **Programming Languages & Frameworks**: Angular, .NET, SQL, TypeScript, Python, Node.js, Express, FastAPI, PowerShell, Bash.
*   **Methodologies & Practices**: Agile/Scrum, DevOps, CI/CD pipelines, Site Reliability Engineering (SRE), Infrastructure-as-code, Configuration Management, Observability.
*   **Cloud & Infrastructure**: AWS, Cloud Architecture Design, Containerization Platforms (e.g., Kubernetes implied), Ansible, GitHub, Infrastructure Automation, IT infrastructure, Windows, Linux.
*   **Software Engineering Principles**: Web development, Software patterns, Data structures, Algorithms, Basic system design.
*   **Security & IT Operations**: SSO, VPNs, MFA, SCIM, JIT provisioning, APIs, automation, IAM, Jira Service Management, JumpCloud, Okta, Google Workspace (Enterprise), Office 365, Salesforce, IT support.
*   **Data Formats**: JSON, YAML.

## Preferred Skills

*   **Advanced Software Concepts**: Software architecture, Distributed systems, Databases, Web server development, API integration.
*   **Cloud Platforms**: AWS, GCP, Azure, AWS certification, Serverless computing.
*   **Languages & Technologies**: TypeScript, Node.js, Python, Java, React, FastAPI, Postgres, Redis, Gitlab, Kubernetes, Datadog, Amplitude, Snowflake.
*   **Specialized Domains**: Universal Scene Description (.USD), NVIDIA Omniverse, DCC Software, CAD, spatial computing.
*   **Industry Specific**: Capital markets, Fintech, Regulated industries.
*   **Project Management**: Azure DevOps, agile workflows, project management methodologies.

## Experience

Internship or 3-5 years, with some postings requiring 8 months of web development work experience.

## Education

Currently enrolled in a post-secondary program (university or college), preferably in Computer Science, Engineering, or a related field, or equivalent practical experience.

## Salary

Salaries for co-op/intern roles range from $757.85 - $1,010.46 per week to $27.00 - $29.00 / hr. Experienced roles show ranges from $75,000 to $141,900.00 annually.

## Responsibilities

*   Develop and implement new functionality or enhance existing applications.
*   Participate in testing (functional, unit, integration, system, UAT).
*   Collaborate with cross-functional teams.
*   Design and automate infrastructure or pipelines.
*   Troubleshoot and resolve technical issues.
*   Contribute to documentation.
*   Provide technical leadership or mentorship (for experienced roles).
*   Identify and automate manual processes.

## Industry Trends

*   Strong demand for cloud platforms (AWS, Azure) and DevOps practices (CI/CD, automation, SRE).
*   Emphasis on modern web development frameworks and languages (Angular, Node.js, Python, TypeScript).
*   Increasing focus on data-driven approaches and API integration.
*   Prevalence of co-op/internship opportunities, suggesting investment in early career talent development.
*   Automation and efficiency are key themes across various roles, including infrastructure and business processes.
*   Security considerations (SSO, VPNs, MFA, IAM) are crucial in IT administration roles.
